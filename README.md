# Bus-crowd-delay-predictor

A web platform that predicts bus delays and crowd levels so commuters can plan trips and operators can manage overloaded routes.

## Features
- Delay prediction using historical trip, traffic and weather data
- Crowd-level classification (low / medium / high)
- Peak-hour demand forecasting by route
- Advisory dashboard with confidence and key factors

## Tech Stack
React, FastAPI, PostgreSQL, scikit-learn, pandas, statsmodels
